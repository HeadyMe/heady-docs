🔐 Authentication & Security Model

🔑

API Gateway Auth

All API requests authenticate via HEADY_API_KEY at the Gateway layer (Layer 2). Admin operations require ADMIN_TOKEN.

🛡️

mTLS & Edge Security

Cloudflare Edge Workers handle SSL termination, DDoS protection, and rate limiting before traffic reaches the Gateway.

🔒

Service-to-Service

Internal services use scoped tokens with least-privilege access. All secrets managed via environment variables — never hardcoded.

📋

Vector-Native Security

Patent HS-062 covers geometric threat detection directly in embedding space. See patent filing.
